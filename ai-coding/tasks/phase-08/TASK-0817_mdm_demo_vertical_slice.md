# TASK-0817 MDM Demo 垂直切片

## 目标

在 JH QMS 模块化单体内增加 MDM 模块，交付元数据驱动的模型查询与动态主数据维护首个可运行切片。

## 本次范围

- 新增 `iaf-mdm` 后端模块与数据库 migration。
- 数据域、模型、字段、UI Schema 查询。
- 物料主数据动态记录的分页、创建、修改、版本快照与乐观锁。
- 模型中心、物料主数据工作台、权限、菜单、i18n 与测试。
- 模型草稿创建、字段/UI Schema 设计、定义校验与不可变发布快照。
- 更新 ADR、模块规格和 code map。

## 后续阶段

1. 已完成模型设计器首版；后续补充已发布版本派生草稿与向后兼容性差异检查。
2. Excel 粘贴、模板/文件预检查与任务跟踪已完成；后台分批提交、断点恢复和部分成功标记为待完成（Demo 优先级调整，暂缓）。
3. JSON Logic 校验与跨模型引用校验（当前任务）。
4. 审批、发布、生效日期与状态机。
5. Outbox、订阅、映射、连接器与重试。
6. 重复治理、Crosswalk 与合并。
7. 联动预览和异步任务。

- 已发布模型 Schema 可通过 API 获取。
