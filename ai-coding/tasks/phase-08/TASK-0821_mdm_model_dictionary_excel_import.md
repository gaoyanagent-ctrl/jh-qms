# TASK-0821 MDM 模型数据字典 Excel 导入

## 目标

让模型管理员将 ERP、MES、WMS、QMS 等系统的数据字典整理为一个工作簿，一次预检多个模型及字段，查看与现有模型的结构差异后再生成模型草稿。

## 工作簿

- `模型定义`：数据域、模型编码、名称、记录类型及能力开关。
- `字段定义`：模型编码、字段编码、名称、类型、长度、必填、唯一、只读、搜索、排序、列表显示、说明和顺序。
- `枚举选项`：枚举字段的值、显示名称和顺序。
- `关联定义`：Reference 的目标模型、值字段、显示字段、状态字段和允许状态。
- 后续扩展 `布局配置`、`校验规则`，格式必须向后兼容。

## 安全约束

- 上传先解析、校验和计算差异，不直接写库。
- Excel 中缺失的已有字段默认保持，不推断删除。
- 已发布模型只能形成新草稿，不能覆盖已发布版本。
- 确认写入后仍必须走模型发布审批。
- 使用模型编码和字段编码引用，不使用数据库 ID。

## 本切片范围

- 下载标准工作簿模板。
- 上传 `.xlsx`/`.xls` 并预检模型、字段、枚举和关联定义。
- 返回新增模型、更新模型、字段新增/修改/不变以及逐行错误。
- 模型中心提供上传、加载反馈、汇总和差异表。

## 后续切片

- 用户确认后原子生成或更新模型草稿。
- 导出现有租户模型数据字典。
- 布局和校验规则 Sheet。
- 导入任务持久化、原文件归档和结果报告。

## 验收

- 一个工作簿可以描述多个模型。
- 重复编码、非法类型、无枚举选项和失效 Reference 能定位到 Sheet、行和字段。
- 预检不修改数据库。
- 已有字段未出现在 Excel 时不会被标记为删除。
