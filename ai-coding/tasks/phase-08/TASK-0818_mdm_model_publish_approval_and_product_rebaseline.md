# TASK-0818 MDM 模型发布审批与原始需求重新基线化

## 目标

将“模型定义发布审批”与“主数据记录生效审批”分离，并重新以 MDM-X 原始需求校准后续 Demo 路线。

## 本次范围

- 模型草稿提交发布审批，审批期间锁定编辑。
- 独立配置模型发布审批角色。
- 使用平台 `ApprovalApplicationService` 保存审批实例与动作。
- 审批通过后生成不可变模型版本并发布；拒绝后返回草稿。
- 审批任务中心统一展示模型发布任务与数据记录任务。
- 更新权限、数据库迁移、模块规格和代码地图。

## 后续范围

1. 真正可持续编辑的 Excel/Grid 模式：单元格编辑、批量选择、批量更新和删除。
2. 表单与 Grid 共用变更集和统一保存管线。
3. 可视化关联校验编排、失焦校验及阻断/警告策略。
4. 联动规则、影响预览、异步执行、防循环与审计。
5. 外部系统、字段映射、订阅、Outbox、重试、重发与分发追踪。

## 验收

- 未审批模型不能发布或打开数据工作台。
- 模型提交后出现在配置角色成员的待审批列表中。
- 发起人不能审批自己的模型发布申请。
- 审批通过才增加模型版本；拒绝不增加版本。
- 模型审批和数据审批在页面上可以明确区分。
