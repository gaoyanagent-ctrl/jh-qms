# TASK-0819 MDM 可编辑 Grid 与统一变更集

## 目标

补齐原始需求中业务实例数据的 Excel/Grid 编辑主路径，并让 Grid 与表单修改进入同一待保存变更集。

## 范围

- 草稿和驳回记录支持表格单元格编辑。
- 表格与表单修改写入同一前端变更集，统一批量保存。
- 支持行选择、批量删除、放弃未保存修改。
- 批量保存和批量删除由后端事务保证原子性，并使用记录版本做乐观锁检查。
- 只读字段和不可编辑生命周期状态不得通过 Grid 修改。
- 更新权限、数据库迁移、测试、模块规格和代码地图。

## 非范围

- Excel 文件导入继续暂缓。
- 跨页选择、离线草稿、撤销栈和多人协同编辑。
- 已生效记录的批量停用或绕过审批修改。

## 验收

- 用户可直接编辑列表中的业务编码、名称和可维护动态字段。
- 表单保存后不立即请求后端，而是回到同一待保存队列。
- 批量保存失败时数据库不产生部分更新。
- 批量删除前有明确确认，且只允许删除草稿/驳回记录。
- 版本冲突返回统一错误，不覆盖其他用户修改。
