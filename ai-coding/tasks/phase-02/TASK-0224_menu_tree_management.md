# TASK-0224 菜单树结构管理增强

## 1. 任务目标

完善菜单管理控制台，使平台管理员可以直观调整菜单所属分组和同级顺序，并控制菜单树的折叠与展开。

## 2. 任务范围

- 菜单树支持逐节点、全部展开和全部折叠。
- 菜单支持同级上移、下移。
- 菜单支持调整到其他菜单分组或根级。
- 结构调整继续使用现有租户隔离菜单更新 API 和 `platform:menu:update` 权限。
- 补充中英文文案、mock 行为、单元测试和前端 code map。

## 3. 非目标

- 不修改菜单表结构。
- 不新增权限点。
- 不改变运行时侧栏的用户偏好模型。
- 不在本任务补齐租户管理 PC 页面。

## 4. 验收标准

- 有更新权限的用户能调整分组和同级顺序。
- 无更新权限的用户只能查看菜单树。
- 上移/下移边界动作不可用。
- 调整分组时不能选择自身或后代节点。
- 全部展开/折叠按钮和行内图标按钮具有可访问名称。
- 前端测试、类型检查和构建通过。
