# TASK-0225 生产发布并发与版本防覆盖门禁

## 目标

防止不同 Agent 从不同 worktree 使用同一 Compose 项目名覆盖线上版本，确保生产前端可追溯、串行发布，并默认只允许发布已进入 `origin/main` 的提交。

## 范围

- 生产前端镜像使用提交 SHA 不可变标签。
- 镜像写入 `org.opencontainers.image.revision`。
- 发布脚本使用主机级文件锁串行化多个 worktree 的发布。
- 默认拒绝脏工作区和未进入 `origin/main` 的提交。
- 发布前执行菜单分组、QMS 翻译和菜单管理回归测试。
- 发布后校验容器镜像、revision、首页和健康接口。

## 验收

- 两个 Agent 不能同时执行生产发布。
- 无法从落后或未集成分支无提示覆盖线上。
- 线上容器可查询到准确提交 SHA。
- 菜单分组回归测试失败时不会替换现有容器。
