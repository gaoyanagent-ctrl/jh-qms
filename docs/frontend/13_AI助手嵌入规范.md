# AI 助手嵌入规范

## 1. 定位

AI 助手是 IAF 前端的一等能力，用于解释页面、解释状态、提示下一步操作、辅助查询、辅助填表和解释错误。

## 2. 展示位置

PC 端：

- 右侧抽屉
- 右侧常驻面板
- 页面级帮助入口

移动端：

- 底部浮动入口
- 错误提示中的“问 AI”

## 3. 前端包结构

```text
packages/ai-assistant/
  AssistantPanel
  PageContextProvider
  BusinessContextBuilder
  SuggestedActionList
  ExplainStatusCard
  AskAboutThisPage
```

## 4. PageAIContext

```ts
type PageAIContext = {
  module: string;
  objectType?: string;
  objectId?: string;
  pageType: 'list' | 'form' | 'detail' | 'task' | 'designer' | 'dashboard';
  currentStatus?: Record<string, string>;
  permissions: string[];
  availableActions: string[];
  visibleFields: string[];
  validationErrors?: string[];
  routePath: string;
};
```

## 5. 第一版能力

- 解释当前页面用途
- 解释当前单据状态
- 提示下一步动作
- 解释错误信息
- 生成查询条件建议
- 帮助填写表单字段说明
- 解释审批意见
- 解释库存异常

## 6. 安全边界

AI 助手不能绕过权限。前端提供给 AI 的上下文必须只包含当前用户可见字段、可见动作和可访问数据。

## 7. Codex 规则

- 复杂业务页面必须实现 `buildPageAIContext`。
- AI 助手不得直接读取 DOM。
- AI 助手调用后端接口必须通过统一 api-client。
- 不允许将隐藏字段或无权限字段传给 AI 上下文。
