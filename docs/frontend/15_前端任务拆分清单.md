# 前端任务拆分清单

本文件是前端路线图和任务拆分总览，不是正式执行任务源。

正式前端任务必须放在：

```text
ai-coding/tasks/frontend/
```

Agent 执行前端任务时，应读取 `ai-coding/tasks/frontend/TASK-FE-*.md` 中的具体任务文件。本文件只用于理解阶段规划和任务拆分背景。

## 1. 阶段划分

```text
Phase FE-00 前端工程初始化
Phase FE-01 基础包建设
Phase FE-02 PC 框架建设
Phase FE-03 移动框架建设
Phase FE-04 低代码列表表单
Phase FE-05 WMS 页面样板
```

## 3. 任务粒度原则

每个任务应满足：

- 只涉及一个明确能力域。
- 能在一次 Codex 会话内完成主要代码。
- 必须包含测试与自检。
- 不能同时大规模改 PC 和移动。
- 不能同时引入新框架和业务页面。
