# 简洁模式与专家模式规范

## 1. 目标

IAF 要同时支持普通业务用户和高级业务用户。简洁模式降低操作复杂度，专家模式提供完整能力。

## 2. 简洁模式

适合：

- 普通仓库作业用户
- 只处理固定任务的业务人员
- 新用户

特点：

- 字段更少
- 按钮更少
- 突出下一步动作
- 隐藏低频配置
- 默认查询条件少
- 只展示关键状态

## 3. 专家模式

适合：

- 主管
- 计划员
- 仓库管理员
- 实施顾问
- 系统管理员

特点：

- 完整字段
- 完整操作
- 高级查询
- 批量操作
- 配置入口
- 关联数据
- 调试信息预留

## 4. 实现方式

不做两套页面，使用统一页面 + ViewMode：

```ts
type ViewMode = 'simple' | 'expert';
```

列表、表单、详情配置必须支持 `viewMode` 条件。

## 5. 默认策略

- 普通用户默认 simple。
- 管理员、主管、实施顾问默认 expert。
- 用户可以在个人设置中切换。
- 某些移动作业页只允许 simple。

## 6. Codex 规则

- 标准列表页必须支持 viewMode。
- 标准表单页必须支持 viewMode。
- 业务动作必须按 viewMode 过滤。
- 不允许通过复制页面实现两个模式。
