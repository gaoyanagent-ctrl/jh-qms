# 组件体系规范

## 1. 组件分层

```text
ui-core          纯 UI 和布局组件
ui-business      通用业务组件
module-components 模块内组件
page-components  页面组合组件
```

## 2. ui-core 组件

必须优先提供：

- PageContainer
- SearchPanel
- ActionBar
- DataTable
- EditableLineTable
- DetailDescriptions
- StatusTag
- ConfirmActionButton
- EmptyState
- ErrorState
- LoadingState

## 3. ui-business 组件

- OrgSelector
- PlantSelector
- WarehouseSelector
- LocationSelector
- MaterialSelector
- SupplierSelector
- CustomerSelector
- UserSelector
- RoleSelector
- ApprovalTimeline
- AuditTimeline
- AttachmentPanel
- BusinessActionBar
- StateTransitionButton

## 4. WMS 业务组件

- MaterialBarcodeInput
- LocationBarcodeInput
- InventoryStatusTag
- BatchNoInput
- SerialNoListInput
- QuantityInput
- WarehouseLocationTree
- PutawaySuggestionPanel
- InventoryBalanceCard

## 5. 组件 API 要求

所有公共组件必须满足：

- TypeScript 类型完整
- 支持 i18n
- 支持 theme token
- 支持 disabled / readonly
- 支持 loading
- 支持 test id
- 不直接调用业务 API，除非是明确的 selector 组件

## 6. 禁止重复造组件

Codex 生成页面时，必须先检查是否存在可复用组件。禁止在业务页面中重复实现物料选择、供应商选择、仓库选择、库位树、状态标签、审批时间线等组件。
