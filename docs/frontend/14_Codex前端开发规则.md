# Codex 前端开发规则索引

本文件只作为前端规格包中的规则入口索引，不维护独立规则清单。

前端可执行规则的唯一权威文件是：

```text
ai-coding/rules/03_frontend_rules.md
```

前端任务正式来源是：

```text
ai-coding/tasks/frontend/
```

前端架构、体验、组件、主题、i18n、权限、移动作业、离线和 AI 助手的详细说明位于：

```text
docs/frontend/
```

执行前端任务时按以下顺序阅读：

1. `AGENTS.md`
2. `docs/architecture/06_项目文档与规则目录治理.md`
3. `ai-coding/rules/03_frontend_rules.md`
4. `docs/frontend/00_README.md`
5. 与任务相关的 `docs/frontend/*`
6. 当前 `ai-coding/tasks/frontend/TASK-FE-*.md`
7. `docs/code-map/frontend.md`
8. `docs/quality/quality_gate.md`

若本目录中的规格说明与 `ai-coding/rules/03_frontend_rules.md` 冲突，以 `ai-coding/rules/03_frontend_rules.md` 为准，除非 ADR 另有规定。
