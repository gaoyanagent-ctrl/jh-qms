# 多语言设计规范

## 1. 目标

第一版必须支持中文和英文，且预留后续语言扩展。多语言范围包括前端页面、菜单、字段、字典、枚举、后端异常和低代码配置元数据。

## 2. 前端 i18n 目录

```text
packages/i18n/
  locales/
    zh-CN/
      common.json
      platform.json
      manufacturing.json
      wms.json
      errors.json
    en-US/
      common.json
      platform.json
      manufacturing.json
      wms.json
      errors.json
```

## 3. i18n key 规范

```text
common.action.create
common.action.update
common.message.unsavedChanges
menu.wms.receipt
wms.receipt.field.documentNo
enum.documentStatus.DRAFT
error.wms.receipt.qtyExceedsExpected
```

## 4. 页面编码规范

错误：

```tsx
<Button>新增</Button>
```

正确：

```tsx
<Button>{t('common.action.create')}</Button>
```

## 5. 后端异常多语言

后端响应必须包含：

```json
{
  "code": "WMS_RECEIPT_QTY_EXCEEDS_EXPECTED",
  "message": "实收数量不能大于应收数量",
  "messageKey": "error.wms.receipt.qtyExceedsExpected",
  "args": { "materialCode": "MAT001" }
}
```

前端优先使用 `messageKey` 翻译。若缺失翻译，则显示后端 message 和 code。

## 6. 菜单 / 字典 / 字段多语言

后端配置必须包含：

```text
display_name
i18n_key
```

前端显示时：

```text
优先 i18n_key -> 当前语言文案
否则 display_name
否则 code
```

## 7. 低代码配置多语言

表单字段、列表列、查询条件、按钮、帮助文本都必须保存 i18nKey。
