# 代码规范

## 1. Java 后端规范

### 命名

| 类型 | 规范 | 示例 |
|---|---|---|
| Controller | XxxController | ReceiptOrderController |
| Application Service | XxxAppService | ReceiptOrderAppService |
| Domain Service | XxxDomainService | InventoryPostingDomainService |
| Repository Interface | XxxRepository | ReceiptOrderRepository |
| Persistence Adapter | XxxRepositoryImpl | ReceiptOrderRepositoryImpl |
| Entity | XxxEntity | ReceiptOrderEntity |
| DTO | XxxDTO | ReceiptOrderDTO |
| Command | XxxCommand | SubmitReceiptOrderCommand |
| Query | XxxQuery | ReceiptOrderPageQuery |
| Event | XxxEvent | ReceiptOrderPostedEvent |

### 分层规则

```text
Controller -> Application Service -> Domain Service/Repository -> Infrastructure
```

禁止：

```text
Controller -> Mapper
Controller -> Domain Entity 直接改状态
Domain -> Infrastructure Adapter
Platform -> Scenario Module
```

### 事务规则

- 事务放在 Application Service。
- 领域服务不直接声明事务，除非有明确理由。
- 外部接口调用不放在数据库事务内，使用 Outbox 或事务后事件。
- 并发敏感业务必须使用 version 或唯一约束防重。

### 异常规则

- 使用统一 BusinessException。
- 每个业务异常必须有错误码。
- 不向前端暴露 Java 堆栈。
- 不吞异常。

## 2. TypeScript 前端规范

### 命名

| 类型 | 规范 | 示例 |
|---|---|---|
| Page | XxxPage | ReceiptOrderListPage |
| Component | XxxPanel / XxxModal | ReceiptOrderApproveModal |
| Hook | useXxx | usePermission |
| Service | xxxService | receiptOrderService |
| Type | XxxDTO / XxxVO | ReceiptOrderDTO |

### 页面规则

- 列表页使用 ProTable。
- 表单页使用 ProForm。
- 详情页采用统一 DetailLayout。
- 权限按钮使用 PermissionButton。
- 字典和枚举从后端或统一字典 hook 加载。
- 不在页面中实现复杂业务规则。

## 3. SQL 规范

- 表名使用模块前缀，例如 `wms_receipt_order`。
- 字段名使用 snake_case。
- 所有时间字段使用 `created_at`、`updated_at`。
- 所有业务主键使用雪花 ID 或统一 ID 生成器。
- 编码字段必须有唯一约束，至少在 tenant_id 范围内唯一。
- 查询条件高频字段必须建索引。

## 4. API 规范

```text
GET    /api/wms/receipt-orders
GET    /api/wms/receipt-orders/{id}
POST   /api/wms/receipt-orders
PUT    /api/wms/receipt-orders/{id}
POST   /api/wms/receipt-orders/{id}/submit
POST   /api/wms/receipt-orders/{id}/approve
POST   /api/wms/receipt-orders/{id}/post
```

响应统一：

```json
{
  "success": true,
  "code": "OK",
  "message": "success",
  "data": {}
}
```

分页统一：

```json
{
  "records": [],
  "pageNo": 1,
  "pageSize": 20,
  "total": 100
}
```
