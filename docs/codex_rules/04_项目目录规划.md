## 6. 目录规则

1. 平台模块不得依赖制造模块或 WMS 模块。
2. manufacturing 通用模块不得依赖 WMS 模块。
3. WMS 模块可以依赖 platform、manufacturing、wms-core、wms-master、wms-inventory 等必要模块。
4. shared 只能放无业务倾向的基础类型、异常、结果封装、工具类。
5. iaf-app 只负责启动和装配，不放业务逻辑。
6. generated 代码必须标识生成来源，手工修改需要注明原因。
