# IAF 技术选型报告 v1.0

## 1. 后端选择
第一版主业务平台建议采用 Spring Boot，不建议使用 Go 作为主业务系统框架。Go 可用于边缘采集、网关、接口代理和高并发数据接入。

## 2. 推荐后端技术栈
- Spring Boot 3.x
- Java 21
- 模块化单体 + 轻量 DDD
- MyBatis Plus + Mapper XML
- PostgreSQL 优先，MySQL 可兼容
- Flyway
- Spring Security + JWT
- Redis
- MinIO
- Flowable 内核 + 自研 Approval DSL
- JSON Logic + 自研规则模型
- Outbox 表 + 调度器
- EasyExcel
- springdoc-openapi
- JUnit 5 + Testcontainers

## 3. 推荐前端技术栈
- React + TypeScript
- Ant Design Pro + ProComponents
- TanStack Query 或 ahooks useRequest
- Zustand
- ProTable
- ProForm
- ECharts
- React Flow / 自研 Canvas
- JsBarcode / QRCode

## 4. 数据策略
标准表 + ext_json + Flyway migration。核心字段为真实列，个性化字段进入 ext_json，高频查询字段后续升级为真实列。

## 5. 不建议第一版采用
- 完整 Spring Cloud 微服务
- 完整低代码运行时
- Drools 重型规则引擎
- Kafka/NATS
- 完全自研 UI 体系
