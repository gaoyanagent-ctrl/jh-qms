# IAF 核心平台模块设计 v1.0

## 1. 模块总览
- 用户与认证
- 组织与多组织
- 权限
- 字典与参数
- 编码规则
- 附件
- 审计日志
- 审批流
- 状态机
- 规则引擎
- Outbox
- 报表
- 打印与条码
- 看板
- 集成中心

## 2. 多组织模型
管理组织：Tenant、Group、Company、BusinessUnit、Department、Position、User。
制造运营组织：Plant、Workshop、ProductionLine、WorkCenter、Warehouse、WarehouseArea、Location。

## 3. 权限模型
权限包括菜单、按钮、API、数据、字段、审批节点字段、单据操作、外部用户、组织隔离。权限编码采用 `模块:对象:动作`，例如 `wms:receipt:approve`。

## 4. 状态机
业务单据区分：document_status、approval_status、execution_status、posting_status、settlement_status。

## 5. 审批流
对外暴露 Approval DSL；内部转换为 Flowable BPMN。核心对象包括 ApprovalDefinition、ApprovalNode、ApprovalCondition、ApprovalAssigneeRule、ApprovalFieldPermission、ApprovalStateMapping、ApprovalInstance、ApprovalTask。

## 6. 规则引擎
第一版采用 JSON Logic + 可视化规则配置器。规则绑定对象包括业务对象、业务动作、审批节点、状态迁移、页面字段、库存策略、消息通知、打印模板选择。

## 7. 集成中心
协同平台支持企微、钉钉、飞书。ERP 通过 Integration Center 管理接口定义、认证、字段映射、调用日志、错误重试。第一版支持 REST API、中间表/数据库视图、Excel 导入。
