# IAF 工业应用开发框架总体架构蓝图 v1.0

## 1. 背景与目标
IAF 的目标不是替代 IAOS，也不是第一阶段建设完整低代码平台，而是建设一个面向制造企业管理系统的 AI Coding 应用开发框架。它通过统一工程结构、基础平台能力、制造通用模型、业务场景模板、轻量 DSL、源码生成和 AI coding 规范，帮助团队快速开发 WMS、MES、SRM、QMS、CRM、成本/RFQ 等应用。

第一阶段的核心目标是解决两个问题：工程重复与制造业务建模困难。工程重复通过基础平台和开发范式解决；业务建模通过标准场景模板逐步沉淀，优先从 WMS 开始。

## 2. 系统定位
IAF 是可产品化的开发框架，早期表现为脚手架、模板、规范和基础平台，后续逐渐沉淀为项目交付底座，并最终成为 IAOS 的轻量前置形态。

## 3. 与 IAOS 的关系
- IAF：近期可落地，源码生成，模块化单体，项目交付优先。
- IAOS：长期目标，语义运行时，Capability Runtime，Agent Runtime，生态化优先。

## 4. 设计原则
- 源码生成优先，不做完整动态运行时。
- 模块化单体优先，保留未来拆分能力。
- 制造业务范式优先，沉淀单据、状态机、审批、规则、库存事务。
- AI coding 可控优先，自然语言先转结构化任务和 DSL。
- 多组织内置。
- 平台能力产品化。

## 5. 总体架构
```text
AI Coding Layer → Web Application Layer → Application Service Layer → Domain Layer → Platform Capability Layer → Manufacturing Common Layer → Scenario Template Layer → Infrastructure Layer
```

## 6. 第一阶段范围
- 基础平台：用户、组织、角色、权限、菜单、字典、附件、审计、编码规则。
- 业务运行底座：状态机、审批流、规则引擎、Outbox、消息通知、导入导出。
- 制造通用模型：多组织、多工厂、多仓库、物料、供应商、客户、BOM、工艺路线、工作中心。
- WMS 模板：采购收货、上架、库存余额、库存明细、库存事务、上架策略。
- 设计器：审批流程、打印模板、条码标签、看板。
- AI coding 规范包。
