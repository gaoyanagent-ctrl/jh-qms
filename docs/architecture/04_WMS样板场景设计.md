# IAF WMS 样板场景设计 v1.0

## 1. 定位
WMS 第一阶段不是完整 WMS 产品，而是 IAF 的第一个标准场景模板，用于验证基础平台、制造主数据、业务单据、审批、状态机、规则、策略、打印、条码、报表和 AI coding 流程。

## 2. 第一阶段业务闭环
基础资料设置 → 采购订单/到货信息 → 收货单 → 收货确认 → 质检状态预留 → 生成上架任务 → 上架策略推荐库位 → 上架确认 → 库存增加 → 库存事务记录 → 库存查询/报表/看板。

## 3. 基础资料
仓库、库区、库位、物料包装、批次规则、序列号规则、上架策略、条码规则。

## 4. 入库与上架
采购收货、收货确认、质检预留、上架任务、上架执行、库存事务、库存余额。

## 5. 库存模型
库存余额维度：物料、仓库、库位、批次、序列号、货主、库存状态、质量状态、数量、可用数量、冻结数量、占用数量。
库存事务必须记录业务来源、物料、来源/目标库位、批次、数量、操作人、发生时间。

## 6. 上架策略
第一版支持固定库位策略、物料分类库区策略、空库位优先策略、同物料集中策略。

## 7. 权限与审批
收货单支持创建、修改、提交、审核、确认收货、生成上架任务、取消、关闭、导出。库存调整、库存冻结、反向过账预留审批能力。
